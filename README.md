# 💄 Passoia - Landing Page de Maquiagem

![Preview do Projeto](https://i.imgur.com/Z1aWE66.png)

Uma landing page moderna e elegante para uma marca de maquiagem, desenvolvida com React.js + Vite e organizada em componentes reutilizáveis.

## 🚀 Sobre o Projeto

A **Passoia** é uma landing page responsiva que apresenta uma marca fictícia de maquiagem, destacando produtos de beleza com um design sofisticado e atraente. O projeto foi desenvolvido utilizando React.js com Vite e uma arquitetura baseada em componentes.

## ✨ Funcionalidades

- **Design Responsivo** - Adaptável para desktop, tablet e mobile
- **Navegação Suave** - Menu de navegação funcional
- **Animações Suaves** - Efeitos visuais modernos

## 🛠️ Tecnologias Utilizadas

- **React.js** - Biblioteca JavaScript para construção da interface
- **Vite** - Build tool e dev server rápido
- **CSS3** - Estilização moderna com flexbox e grid
- **HTML5** - Estrutura semântica

## 🎨 Design e Estilo

- **Paleta de Cores**: Tons elegantes e femininos adequados para maquiagem
- **Tipografia**: Fontes modernas e legíveis
- **Layout**: Design limpo com foco na experiência do usuário
- **Imagens**: Seleção de imagens que representam a marca Passoia

## 📱 Responsividade

O projeto foi desenvolvido com foco em responsividade, garantindo:
- Experiência otimizada em dispositivos móveis
- Adaptação fluida para tablets
- Layout consistente em desktops

## 🚀 Como Executar o Projeto

```bash
# Clone o repositório
git clone https://github.com/rsvdrigo/LandingPagePassoia.git

# Acesse o diretório
cd LandingPagePassoia

# Instale as dependências
npm install

# Execute o projeto
npm run dev
```

O projeto estará disponível em `http://localhost:5173`

## 📦 Scripts Disponíveis

- `npm run dev` - Executa o projeto em modo de desenvolvimento
- `npm run build` - Gera build de produção
- `npm run preview` - Preview do build de produção
